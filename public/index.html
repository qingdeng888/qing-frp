GitHub 代理 / 镜像（服务器访问 GitHub 不畅时使用）

多数前缀代理不支持 GitHub API（实测返回 403）。不勾选时「最新版本检测」仍走直连， 只把文件下载走代理——这样不会因为 API 不通导致误报。
二进制直链托管
把 frp 安装包托管到 OpenList / 对象存储 / CDN，节点安装时优先从这些直链下载， 减轻面板带宽压力。每个文件可填各自的完整直链（含签名参数）。
文件请填面板实际分发的资产名（如 frp_0.71.0_linux_amd64.tar.gz）。未配置的文件自动走面板分发。
地址填完整直链，签名参数请一并粘贴（如 OpenList 的 ?sign=xxx:0）。
回退直链失效（签名过期 / 存储故障 / 404）时会自动改用面板分发，安装不会中断。
一键列出 6 个 Linux 架构的文件名，方便逐个贴直链
